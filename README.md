# Project 1 - Zara Sales Analysis

**Title** [zara](https://github.com/Chiomy12/Chiomy12.github.io/blob/main/Zara%20Power%20BI%20Dashboard%20(1).pbix)

**Project Description**<br> This project analyses Zara retail sales data to understand product performance, sales volume and revenue patterns.
The analysis focuses on identifying top-performing and underperforming products and generating insights that could support inventory planning, stock replenishment and retail decision-making. The project demonstrates the use of Microsoft Excel, Power Query and Power BI to clean, analyse and visualise retail sales data.

**Tools Used**
Excel | Power Query | Pivot Tables | Data Visualisation
**Key Findings**
- Jackets were the top-performing product category based on sales performance.
- Jackets generated $26,581,815.87 in total sales.
- A total of 259,468 units of jackets were sold.
- Product performance was evaluated using both total sales revenue and sales volume.

# Project 2 - Coffee Shop Sales Analysis

**Title** [coffee](https://github.com/Chiomy12/Chiomy12.github.io/blob/main/Priject%202%20-%20Coffee%20Shop%20Sales%20Analysis/coffee%20shop%20sales.xlsx)

**Project Description** <br> This project analyses coffee shop transaction data to understand sales performance, product demand and customer purchasing patterns. The analysis explores revenue, average transaction value, best- and least-selling products, and sales performance across different times of the day.

**Tools Used**<br>
Excel | Power Query | Pivot Tables | Data Visualisation

**Key Findings**
- Analysed total revenue and average transaction value to understand overall sales performance.
- Identified the best-selling and least-selling products.
- Analysed sales by time of day to identify the period with the highest sales.
- Used Pivot Tables, slicers and visualisations to explore sales patterns and present insights through an interactive dashboard
