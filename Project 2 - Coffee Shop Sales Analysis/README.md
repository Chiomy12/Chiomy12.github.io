# Data Analytics Portfolio

# Project 2 - Coffe Shop Sales Analysis

**Title** [Coffee](https://github.com/Chiomy12/Chiomy12.github.io/tree/main/Project%202%20-%20Coffee%20Shop%20Sales%20Analysis)

**Project Description**<br>

This project analyses coffee shop sales data to understand revenue performance, customer purchasing patterns and product performance. The analysis focuses on identifying sales trends across products, categories, store locations and different times of the day. The project demonstrates the use of Microsoft Excel, Power Query, Pivot Tables and dashboard visualisation to transform raw transactional data into meaningful business insights.

**Project Objectives**<br>
The main objectives of this project were to:
- Analyse overall sales and revenue performance
- Identify key sales and transaction metrics
- Analyse revenue by product category and store location
- Identify top and lower-performing products
- Examine sales patterns across different times and months
- Identify opportunities to improve sales performance
- Build an interactive dashboard to communicate the findings clearly

**Dataset**<br>
The dataset contains transactional sales information from a coffee shop. Key fields used in the analysis include:
- Transaction date and time
- Store location
- Product category
- Product type
- Quantity sold
- Unit price
- Revenue
The dataset was used to analyse sales performance across products, locations and time periods.

**Data Cleaning & Preparation**<br>
Before performing the analysis, the raw dataset was reviewed and prepared to ensure that it was suitable for analysis.

**Power Query**<br>
Power Query in Excel was used to:
- Import and transform the dataset
- Review and correct data types
- Clean and organise the data
- Prepare the data for analysis
- Validate the transformed dataset
The cleaned data was then used for calculations, Pivot Tables and dashboard development.

**Key Findings**<br>
The analysis showed that:
- Total revenue was **$698,812.33**
- The dataset contained **149,116 transactions**
- **214,470** items were sold
- Coffee and Tea were major contributors to overall revenue
- Revenue was relatively evenly distributed across the three store locations
- Sales were strongest during the morning period and declined towards the evening
- There were noticeable differences in performance between individual products

**Business Insights**<br>
The analysis provides insights that could support:

**Product Planning** <br>
Monitoring high-performing products can help maintain sufficient stock availability during periods of strong demand.

**Sales Opportunities** <br>
The lower evening sales pattern could provide an opportunity for targeted promotions or other strategies to increase off-peak sales.

**Product Performance** <br> 
Comparing product and category performance can help identify products that contribute strongly to revenue and those requiring further investigation.

**Dashboard Development**<br>
An interactive Excel dashboard was created to present the analysis through:
- KPI cards
- Revenue analysis
- Product and category analysis
- Store location comparison
- Time-based sales analysis
- Top and lower-performing products
- Interactive slicers
